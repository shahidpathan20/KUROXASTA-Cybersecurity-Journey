## TLS

| Short form | Full Form | meaning |
| --- | --- | --- |
| SSL | Secure Sockets layer | older protocol for securing data |
| TLS | Transport Layer security | Protects data exchanged over a network |
| CA | Certificate Authority | Trusted organisation that issues digital certificates |
| CSR | Certificate Signing Request | Request sent to a CA for a digital certificate |
