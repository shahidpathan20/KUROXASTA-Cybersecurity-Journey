<b>DNS (Domain Name System):</b>

DNS helps us communicate with websites without remembering complex IP addresses.

Instead of remembering numbers like <code>104.26.10.229</code>, we can simply use domain names like <code>tryhackme.com</code>

### TLD(Top-Level Domain)

A TLD is the last part of a domain name that appears after the dot (<code>.</code>).

It helps identify the purpose or type of the website.


Examples 


- <code>.com</code> → Commercial websites
- <code>.org</code> → Organizations
- <code>.edu</code> → Educational websites
- <code>.gov</code> → Government websites
- EXAMPLE

In <code>tryhackme.com</code>, <code>.com</code> is the TLD.

### Subdomain

A subdomain is an additional part added before the main domain name to organize or separate different sections of a website.

It helps create different areas of a website.


EXAMPLE 


In <code>admin.tryhackme.com</code>:

- <code>admin</code> → Subdomain
- <code>tryhackme</code> → Domain Name
- <code>.com</code> → TLD (Top Level Domain)
