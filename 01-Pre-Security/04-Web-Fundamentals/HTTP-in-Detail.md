<b>HTTP</b> stands for( <b>HyperText Transfer Protocol)</b>

It is used for communication between your browser and a website server.

When you open a website, your browser sends an HTTP request to the server, and the server sends back the webpage data.


For Example 


If you visit:

<code>http://one piece.com</code>

your browser and the website exchange data using HTTP.

Problem with HTTP

HTTP is <b>not secure</b> because the data is sent in <b>plain text</b>.

That means if an attacker is connected to the same network (like public Wi-Fi), they may be able to see your usernames, password, message, credit card info, ETC.

## HTTPS

<b>HTTPS</b> stands for( <b>HyperText Transfer Protocol Secure</b>.)

It is the secure version of HTTP.

HTTPS uses:

- <b>SSL/TLS encryption</b><br />to protect the data between the browser and the server.

### Example

<code>https://one piece.com</code>

The <b>lock icon 🔒</b> in the browser means the connection is encrypted.


example 


HTTP

Like sending a postcard.

Anyone who sees it can read the message.

HTTPS

Like sending a locked box.

Only the sender and receiver can open it.
