        HTML



        Hyper Text Markup Language(HTML)  is the basic language used to make websites.

It uses tags (elements) to tell the browser what to show, such as headings, text, images, and links.


JavaScript 


<b>JavaScript (JS)</b> is a language that makes websites do things when you interact with them.

It helps buttons, menus, animations, and other website features work properly.

<b>CSS (Cascading Style Sheets)</b>

is a language used to style and design web pages.

It controls the colors, fonts, spacing, and layout to make a website look attractive.
