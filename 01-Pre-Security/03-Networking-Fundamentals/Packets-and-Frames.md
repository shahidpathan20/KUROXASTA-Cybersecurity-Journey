## PACKETS (Layer 3- Network Layer )


A packet is a data contains IP addressing information 


<ul>
<li>
packets works at data layer 

- contains:
  <ul>
  <li>
  source IP 
  </li>
  <li>
  Destination IP 
  </li>
  <li>
  TTL(Time To Live)
  </li>
  <li>
  Checksum 
  </li>
  </ul>
</li>
<li>
used for routing across network(internet)
</li>
</ul>

A packets is a data with IP addresses used to move accross different networks.

## FRAMS (Layer 2- Data link Layer)


A Frame is data used for communication inside Local area (LAN)

<ul>
<li>
Works at data link (Layer 2)

- contains:
  - Source MAC address
  - destination MAC address
</li>
<li>
Does not contain IP addresses 
</li>
<li>
Used for local delivery (Device to Device)
</li>
</ul>



A frame is data used to moves packets within a local network using MAC addresses.
