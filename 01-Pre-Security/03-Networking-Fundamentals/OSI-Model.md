OSI model is a 7- Layer conceptual framework, how data is send, received , understood across the network. It breaks network communication into layers so each layers handles a specific function.


in a simple sentence 

it explain how data moves from one computer to another step by step.

OSI 7 layers

<h3>
1\. Physical Layer 
</h3>


Send raw data as bits(0s and 1s) through cables or signals 


<h3>
2\. Data link Layer 
</h3>


Transfer data between devises in the same network using MAC address 


<h3>
3\. Network Layer 
</h3>


Find the best path and uses IP address to send data across networks 


<h3>
4\. Transport Layer 
</h3>

Ensure that data delivery using TCP (Transmission control protocol)or fast delivery using UDP(User datagram protocol)

<image source="notion-file-block://3bc21778-a700-80d6-b190-eee8216a3e8f/d47f1e65-edb8-4aac-ade9-aafe213d7d95?space_id=18a21778-a700-8125-9c75-0003ef64b7a1&name=tcp_vs_udp_notes_diagram.png" />

<h3>
5\. Session Layer 
</h3>


Starts, manage and end communication session between devices 


<h3>
6 Presentation Layer 
</h3>


Converts data into readable format  


<h3>
7 Application Layer 
</h3>

Provides network services directly to the user (like browser, email, etc. )
