# Inside a Computer System

A computer system contains hardware components that work together to process information.

- **Motherboard:** connects components.
- **CPU:** executes instructions and processes data.
- **RAM:** temporary working memory for running programs.
- **HDD/SSD:** persistent storage for files and data.
- **PSU:** supplies electrical power.
- **GPU:** processes graphics and video.
- **Network adapter:** enables network communication.
- **Input/output devices:** keyboard, mouse, monitor, and similar peripherals.

## Startup sequence
1. The power supply provides power.
2. BIOS/UEFI initializes hardware and performs POST checks.
3. The bootloader starts from storage.
4. The operating system loads and initializes.
5. The login screen or desktop appears.

**Summary:** CPU processes instructions; RAM holds working data; storage keeps data; the motherboard connects components.
