A computer system is made of different hardware components that work together to perform tasks

<h4>
Main Components 
</h4>

- <b>Motherboard</b> → Connects all computer components together
- <b>CPU (Processor)</b> → Brain of the computer that processes instructions
- <b>RAM</b> → Temporary memory used while programs are running
- <b>Storage (HDD/SSD)</b> → Stores files and data permanently
- <b>Power Supply Unit (PSU)</b> → Provides power to all components
- <b>GPU (Graphics Card)</b> → Handles graphics and video processing
- <b>Network Adapter</b> → Allows communication with other devices/networks
- <b>Input/Output Devices</b> → Devices like keyboard, mouse, and monitor for interaction

#### simple example

Just like organs work together in the human body, all computer components work together to make a computer function properly

#### What happen when you press the start button?

1. <b>Power Supply Starts</b>
   <p>
   The PSU (Power Supply Unit) sends power to all computer components.
   </p>
2. <b>BIOS/UEFI Runs</b>
   <p>
   The BIOS or UEFI checks if the hardware is working properly. This process is called POST (Power-On Self-Test).
   </p>
3. <b>Bootloader Starts</b>
   <p>
   The bootloader is loaded from the storage device (HDD/SSD).
   </p>
4. <b>Operating System Loads</b>
   <p>
   The operating system (Windows/Linux) is loaded into RAM.
   </p>
5. <b>Login Screen Appears</b>
   <p>
   The computer finishes booting and shows the login or desktop screen.
   </p>

   <p>
   Power Button → BIOS/UEFI → Bootloader → Operating System → Desktop Screen  
   </p>
