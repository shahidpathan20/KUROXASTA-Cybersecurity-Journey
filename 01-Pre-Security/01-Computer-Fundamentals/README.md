# Computer Fundamentals

## 1. What Is Cybersecurity?
Cybersecurity is the ongoing effort to protect people, organizations, systems, and data from digital attacks, unauthorized access, or harm.

### Types of Cybersecurity
- **Network security:** protects networks from attacks and unauthorized access.
- **Application security:** secures applications against vulnerabilities.
- **Information security:** protects sensitive information.
- **Cloud security:** secures cloud-based systems and data.
- **Endpoint security:** protects devices such as laptops and phones.
- **Offensive security:** finds weaknesses through authorized security testing.
- **Defensive security:** detects, investigates, and helps stop cyberattacks.
- **Operational security:** protects sensitive processes and controls access.

Offensive security legally tests systems to find weaknesses. Defensive security focuses on monitoring, protection, risk reduction, and response.

## 2. Inside a Computer System
A computer system contains hardware components that work together to process information.

- **Motherboard:** connects components.
- **CPU:** executes instructions and processes data.
- **RAM:** temporary working memory for running programs.
- **HDD/SSD:** persistent storage for files and data.
- **PSU:** supplies electrical power.
- **GPU:** processes graphics and video.
- **Network adapter:** enables network communication.
- **Input/output devices:** keyboard, mouse, monitor, and similar peripherals.

### Startup sequence
1. The power supply provides power.
2. BIOS/UEFI initializes hardware and performs POST checks.
3. The bootloader starts from storage.
4. The operating system loads and initializes.
5. The login screen or desktop appears.

**Summary:** CPU processes instructions; RAM holds working data; storage keeps data; the motherboard connects components.

## 3. Client–Server Basics
Client–server architecture is a model where a client requests a service and a server provides it.

- **Client:** requests a resource, such as a browser.
- **Server:** responds with a service or resource.
- **DNS:** translates domain names into records such as IP addresses.
- **IP address:** identifies a network interface for communication.
- **Port:** identifies a service endpoint on a device.
- **Protocol:** rules used for communication.
- **Network:** connected devices that exchange data.

Example: a browser requests a webpage from a web server, and the server returns data for the browser to display.

## 4. Virtualisation Basics
Virtualisation lets one physical computer or server run multiple virtual machines (VMs).

A useful analogy is a building: the physical server is the building, VMs are apartments, and the hypervisor is the building manager.

- **Hypervisor:** software that creates and manages VMs.
- **Type 1 hypervisor:** runs directly on physical hardware.
- **Type 2 hypervisor:** runs on top of an existing operating system.
- **VM:** virtual computer with virtual CPU, RAM, storage, networking, and its own OS.
- **Container:** lightweight environment that packages an application and its dependencies; containers generally share the host OS kernel.
- **Docker:** widely used container platform.

Virtualisation can improve resource utilization, flexibility, scalability, and cost efficiency.

## 5. Cloud Computing Fundamentals
Cloud computing means accessing computing resources—such as servers, storage, databases, and software—over a network, usually the internet.

Examples include Google Drive for file storage, Gmail for email, and Netflix for streaming. These services rely on infrastructure managed by the provider rather than only on your personal computer.

**Summary:** cloud computing provides on-demand access to computing resources without requiring users to own and manage all underlying hardware.
