# Virtualisation Basics

Virtualisation lets one physical computer or server run multiple virtual machines (VMs).

A useful analogy is a building: the physical server is the building, VMs are apartments, and the hypervisor is the building manager.

- **Hypervisor:** software that creates and manages VMs.
- **Type 1 hypervisor:** runs directly on physical hardware.
- **Type 2 hypervisor:** runs on top of an existing operating system.
- **VM:** virtual computer with virtual CPU, RAM, storage, networking, and its own OS.
- **Container:** lightweight environment that packages an application and dependencies; containers generally share the host OS kernel.
- **Docker:** widely used container platform.

Virtualisation can improve resource utilization, flexibility, scalability, and cost efficiency.
