<h2>
What  is virtualisation 
</h2>

virtualisation is a technology that allows one physical computer  (server)


to rum multiple virtual computer on the same hardware

## Hypervisor (The Building Manager)

A Hypervisor is a software that create and manages virtual machines(VM)

<h3>
Types of Hypervisor 
</h3>

Type 1(Bare Metal)


Runs directly on hardware 


Type two (Hosted)


Runs on the top of an existing operating system 


## Lab Machine or virtual machine(VM) (Apartment )


A Lab Machine (VM) is a virtual machine created by a hypervisor 



VM characteristics 


<ul>
<li>
Has virtual CPU
</li>
<li>
Has virtual RAM
</li>
<li>
Has virtual Storage
</li>
<li>
Has virtual Network interface 
</li>
<li>
runs its own OS
</li>
<li>
isolated from other VMs
</li>
</ul>

<h2>
Containers 
</h2>

A container is a lightweight environment that runs a single appliation with its dependencies


 Key words 


- <b>Virtualization</b> = One physical server → Multiple virtual servers.
- <b>Hypervisor</b> = Manages VMs.
- <b>Type 1</b> = Runs on hardware.
- <b>Type 2</b> = Runs on OS.
- <b>VM</b> = Full virtual computer.
- <b>Container</b> = Lightweight app environment.
- <b>Docker</b> = Most popular container platform.
- <b>VM = Apartment</b>
- <b>Container = Room</b>
- Main benefits: Cost saving, scalability, flexibility, resource optimization
